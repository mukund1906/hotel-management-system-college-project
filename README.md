# Hotel Harmony — Hotel Management System

A responsive college project built with HTML, CSS and JavaScript. It presents sample hotel details, room types, facilities and a front-end booking enquiry form.

## Run locally

Open `index.html` in a browser. The booking form is only a demo and does not send or store enquiries.

## Publish with GitHub Pages

1. Create a **public** GitHub repository for the project.
2. Upload `index.html`, `style.css`, `script.js`, and this `README.md` to the repository's root folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. GitHub will show the published website address in the Pages settings after deployment completes.

## Project files

- `index.html` — page content and sections
- `style.css` — colors, layout and responsive styles
- `script.js` — mobile menu, date validation and demo form response

All hotel details and prices are fictional sample content for this project.
